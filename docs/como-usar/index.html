Guía

Cómo usar un DESIGN.md

Elige un diseño del catálogo, pégalo donde tu IA pueda leerlo y pídele que lo siga. Funciona igual desde el móvil que desde el ordenador. Busca abajo la herramienta que usas.

01

ChatGPT, Claude o Gemini (web o app del móvil)

Elige un diseño y toca «Copiar DESIGN.md». Pégalo en el chat y, en el mismo mensaje o justo después, escribe lo que quieres: «Crea una web para mi peluquería siguiendo este DESIGN.md, en un único archivo HTML». Si quieres retocar algo, pídelo con palabras normales: «botones más grandes», «añade un mapa».

02

Lovable, Bolt, v0 y similares

Pega el DESIGN.md en el primer mensaje o en el apartado de conocimiento o instrucciones del proyecto, y pide que lo respete en cada pantalla.

03

Claude Code / Codex / Gemini CLI (si programas)

Guarda el archivo como DESIGN.md en la raíz del proyecto y escribe: «Lee DESIGN.md y rediseña la página de inicio siguiéndolo». Para que lo tenga siempre presente, añade a tu CLAUDE.md o AGENTS.md la línea: Sigue siempre DESIGN.md para cualquier decisión visual.

04

Cursor / Windsurf (si programas)

Añade DESIGN.md al proyecto y menciónalo en el chat con @DESIGN.md. Si usas reglas, crea una en .cursor/rules que diga que toda la interfaz debe seguir DESIGN.md.

Consejos

  • Un DESIGN.md por proyecto. Si cambias de estilo, sustituye el archivo entero.
  • Personalízalo: cambia el color primary por el de tu marca y pide a la IA que ajuste el resto para mantener el contraste.
  • Si programas, valídalo con npx @google/design.md lint DESIGN.md.
  • Pide cambios en lenguaje normal: «haz los botones más grandes», «usa el acento solo en ofertas».
