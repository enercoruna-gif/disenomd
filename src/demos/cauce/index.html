¿Cauce es una app financiera real?

No. Es un concepto de diseño con datos ficticios. No conecta con bancos, no procesa pagos y no ofrece servicios financieros.

¿Qué incluye el DESIGN.md?

Dirección visual, colores, tipografía, espaciado, componentes, estados, responsive, movimiento y un prompt de uso. Está escrito en español y se descarga en Markdown.

¿Cómo lo uso con mi IA?

Adjunta el archivo y pide: «Crea una landing para mi proyecto siguiendo este DESIGN.md. Adapta los textos y no inventes testimonios ni cifras». Reemplaza Cauce por tu marca.

¿Necesito pagar alguna biblioteca?

No. Esta demo funciona con HTML, CSS y JavaScript nativos. No incluye componentes premium ni requiere cuentas, claves o suscripciones.
